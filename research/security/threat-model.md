# 脅威と seL4 で防げる範囲

[索引へ戻る](../README.md)

この文書は準備段階の整理です。設計が進んだら、脅威ごとの対策と費用を書き足します。

| 脅威 | seL4 で防げる範囲（推測） | 防げない範囲 |
|---|---|---|
| 1 つの部品（driver、アプリケーション）の不具合や乗っ取り | 証明された完全性と機密性により、渡していない capability の資源には触れない | DMA を使う device の driver は IOMMU がないため全メモリに書ける |
| kernel の不具合 | 検証済み構成では、証明の前提の範囲で機能正当性が保証される | 起動処理、SMMU、debug は対象外。ハードウェアの不具合 |
| microSD の取り外し・書き換え | なし（kernel の外の問題） | 署名検証、暗号化は別の部品で設計が必要 |
| 起動経路の改ざん（firmware、elfloader） | なし | BCM2837 には独立した起動時の信頼点がない（推測、未確認） |
| 電源断 | なし（kernel の外の問題） | 書き込みの設計（AGENTS.md §11）と A/B 更新で扱う |
| 物理的な攻撃（debug 端子、bus の盗聴） | なし | 費用に見合う範囲で扱う |
